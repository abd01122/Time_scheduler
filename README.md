## 📱 What is TimeFlow?

TimeFlow is a **smart task scheduler** that helps you organize your day by priority. Tasks are **level-locked** - you must complete higher priority tasks before unlocking lower ones. Perfect for staying focused and building productive habits!


---

## ✨ Features

### 🎯 Priority-Based Task Locking
- Tasks sorted by priority (1-10, highest first)
- **Cannot skip tasks** - complete high priority tasks first
- Unlocks next task only after finishing current ones

### 📊 Productivity Tracking
- Earn points for completing tasks
- Track completion percentage
- Focus session bonus points
- Persistent progress (saves locally)

### 🎮 Gamified Experience
- Level-up style progression
- Points system rewards consistency
- Visual feedback for completed tasks

### 📱 Mobile Ready
- Fully responsive design
- Touch-friendly buttons
- Works on any device with a browser

### 💾 Privacy First
- **No backend** - all data stays on your device
- **No account needed**
- **No passwords** (unless you add them)
- **No time limits**
- Works offline after first visit
